How it works
Front card is identical in size to a single manga card. Wrapper = front card dimensions, no padding.
Back cards are plain solid containers with negative right/bottom anchors → peek beyond the wrapper.
Offsets: mid 6px right · 8px down, far 12px right · 16px down.
Catalog grid needs row-gap ≥ 24px (use 36px for breathing room) so back peeks don't collide with next row.
Cover badges match the single card: rarity top-left, status top-right. Collection / Box Set tag lives in the footer.
